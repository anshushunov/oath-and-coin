# DEC-004 — Причины решений являются частью интерфейса

> Дата: 2026-08-12
>
> Статус: accepted

## Контекст

Автономия без объяснимости воспринимается как случайность.

## Решение

Каждое значимое решение героя хранит и показывает несколько ведущих причин.

## Альтернативы

- Полностью скрытая психология.
- Показ точной utility-формулы.

## Последствия

Data model должен хранить causal trace; UI показывает краткую версию и детализацию.

## Проверка

Гипотеза H3 и инварианты автоматических тестов (GDD §21.4).

GDD §16.4; TDD §8; [DEC-006](DEC-006-ranked-reasons-not-probabilities.md).
