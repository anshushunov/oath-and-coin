# DEC-009 — Шесть портретов героев в Milestone 1 как исключение из DEC-007

> Дата: 2026-08-13
>
> Статус: proposed

## Контекст

`DEC-007` в статусе `accepted` говорит про Milestone 1–3 прямо: «Никакого целевого арта». Правило появилось не из экономии, а из наблюдения: арт — худшая дорожка для агентской разработки, он дорого стоит, плохо параллелится и не проверяется автоматически.

При этом exit criteria Milestone 1 (`MVP_PLAN` §5.5) требуют, чтобы **ни один герой не описывался тестером только через класс или силу**. Проверяется гипотеза «игрок относится к героям как к людям, а не как к юнитам». Шесть безликих карточек с одинаковой заглушкой работают против ровно этого измерения: тестер, которому нечем отличить героев визуально, вернётся к описанию через класс просто потому, что другого различителя у него нет.

Без записи агент, читающий `DEC-007`, будет прав, отказавшись делать портреты, а гипотеза M1 останется непроверенной.

## Решение

- В Milestone 1 делаются **шесть портретов героев** — по одному на героя стартового состава. Больше ничего: ни арта боя, ни фонов, ни иллюстраций событий.
- Это **явное исключение** из `DEC-007`, ограниченное числом шесть и сущностью «портрет героя». `DEC-007` в остальном действует без изменений, включая целевой арт с Milestone 4.
- **Разовый акт, а не пайплайн.** Генерация через ChatGPT, три правила: один общий шаблон промпта на всех шестерых (иначе стиль разъедется), фиксированные размер и кроп, промпты коммитятся рядом с картинками (иначе седьмого героя в том же стиле не сделать).
- **Ссылка на портрет — по стабильному идентификатору героя** (`ADR-005`), а не по имени файла.
- Генерация — **build-time**. Запрет `AGENTS.md` §2 на runtime LLM как источник игрового состояния она не нарушает; зафиксировано явно, чтобы не обсуждать повторно.

## Альтернативы

- **Оставить M1 без портретов** — отклонено: exit criteria M1 измеряют отношение тестера к герою как к человеку, и отсутствие лица искажает измерение в сторону отрицательного результата по причине, не связанной с гипотезой.
- **Процедурные аватары или силуэты** — отклонено: дешевле, но различают героев так же слабо, как класс, то есть не снимают исходную проблему.
- **Полноценный арт-пайплайн под отдельные модели** (Midjourney, Stable Diffusion, Flux) — отклонено: пайплайн под шесть картинок — случай «понадобится потом» из `MVP_PLAN` §15.
- **Расширить исключение на иконки и фоны** — отклонено: исключения не накапливаются (`AGENTS.md` §12 п. 3). Третье исключение из `DEC-007` означает, что переписывать надо `DEC-007`, а не добавлять оговорки.

## Последствия

- Milestone 1 остаётся реализуемым агентами без художника: шесть картинок — разовая ручная работа владельца, а не задача в плане.
- Риск: удачные портреты завышают воспринимаемое качество остального схематичного UI. Он принят — искажение в эту сторону не мешает измерять exit criteria M1.
- Если тестеры M1 всё равно описывают героев через класс, портреты проблему не решили, и вопрос уходит в модель поведения героев, а не в арт.

## Проверка

Автоматического теста у решения нет намеренно: оно продуктовое и проверяется exit criteria Milestone 1 (`MVP_PLAN` §5.5) — долей тестеров, описывающих героев не только через класс или силу. Техническая часть, которую проверить можно, — адресация портрета по идентификатору героя — держится `ADR-005`.

Пересмотр — по итогам Milestone 1: при отрицательном результате исключение не расширяется, а закрывается.
